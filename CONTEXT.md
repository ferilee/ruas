# Ruang Asesmen domain glossary

## Workspace

An admin or teacher's managed area containing the classes, subjects, assessment types, topics, questions, students, schedules, and reports they own.

## Shared curriculum

Curriculum records created by Admin or imported before workspace ownership was introduced. Teachers can use these records as read-only references.

## Teacher-owned data

Curriculum and assessment data created by a teacher. The creating teacher can manage it; other teachers cannot see or change it.

## Admin authority

Admin can view and manage shared data and every teacher workspace, including access and account assignments.

## Teacher access request

A public request from a prospective teacher. It remains pending until Admin approves or rejects it. Approval creates an Editor account with a forced first-login password change.
